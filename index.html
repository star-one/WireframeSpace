      Syntax guide 
      screen "Name"        starts a screen (top level)
Indent by 2 spaces to nest.
# comment

Reusable:   component "Name" (top level), then: use "Name" inside a screen
Layout:     section "Title" (a full-width band)
            columns layout=2:1 (each child = one column; wraps)
            column, card, inline (side by side, no box)
Other:      form, nav, modal
Elements:   heading "Text"   text "Text"   paragraph (Lorem ipsum, or give text)
            input "Label" type=email id=email placeholder="…"
            select "Label" options=One|Two|Three
            checkbox "Label"   image "Caption"   divider
Forms:      form "Name" (one page), or a form containing formpage "Title" blocks (multi-page)
            input "Question" type=email required hint="Help text"
            textarea "Question" rows=6      radios "Question" options=Yes|No
            checks "Question" options=A|B|C select "Question" options=A|B|C
            checkbox "I agree"   date "When" kind=time   file "Upload" accept=image/*
            range "Rating" min=1 max=5   field "Signature" as="Signature pad" (any other type)
            sample = a placeholder field to be replaced by a real question
            table "Title" cols=Name|Status|Due rows=3
            tabs items=Overview|Tasks|Files
            button "Label" -> "Screen"   (style=secondary)
            link "Label" -> "Screen"
            button "Label" opens "Modal title"    (modals sit at the bottom of a screen)
            button "Close" closes                 (inside a modal)
            button "Retry" state=Error            (switches this screen to a state)
States:     screen "Name" states=Default|Empty|Error
            any element: show-in=Empty   or   hide-in=Error|Loading
            note "Why or how it should behave"

-> "Screen" makes any button or link navigate in the preview.
Names and labels are always in quotes: -> "Project details"
Notes become requirements in the AI handoff.
